# Writeups - AHAU CTF 2026

[AHAU CTF](https://ahauteam.org) es una competencia de ciberseguridad en formato Jeopardy dirigida a estudiantes del sureste mexicano (Yucatán, Campeche y Quintana Roo). La edición 2026 se llevó a cabo del 28 al 30 de agosto, de forma remota durante 48 horas, con retos de Cryptography, Web Exploitation, Binary Exploitation, Reverse Engineering, Forensics, Miscellaneous e Inteligencia Artificial.

Este repositorio contiene writeups de todos los retos que resolví junto con mi equipo.
